👨‍👩‍👧 家长提示：这一课真正在种什么种子？

三个案件分别对应：综合评分（F-Score）、价格与价值（基本面锚定反转）、波动与风险（特质波动率）。孩子不需要记术语，只要能说出“不能只看一个指标”“价格会跑远，但不一定马上回来”“太颠不一定更好”。

答错时问：“你觉得这个案子里，最关键的信息是什么？”让孩子先找线索，再一起看答案。

三张案件卡可以打印出来，当成家庭聊天卡：每天抽一张，说说生活里的类似例子。

问一问

三个案子里，你觉得哪个最像生活里的事？
没有标准答案。可以继续问：“为什么？你见过类似的事吗？”
怪事一定都是坏事吗？
不一定。怪事只是“看起来和想的不一样”。找到原因，就可能变成机会；找不到原因，也可能只是运气。
