## 2.1 排序法 —— 📚“按身高分班，比成绩”

**核心问题**：因子收益率的“身价”（λ）怎么算出来？

**三步走**（对应原书 2.1.2 节）：

1. **排队**：用排序变量（如 BM）把股票从高到低排序；
2. **分班**：切成 L 组（惯例 L=10）；
3. **比赛**：高组收益 − 低组收益 = **价差组合收益 = 因子收益率**（资金中性，多空各等额）。

用公式写：

```
价差组合收益_t = R_high,t − R_low,t
```

**两个检验**：

- **t 检验**：这个分差是“真实力”还是“运气”？|t| > 2（95% 置信）才算数；
- **单调性**：是不是“越高的班成绩越好”？—— Spearman 秩相关系数，≈1 表示完美单调上升，≈−1 表示完美单调下降，接近 0 表示没有明显单调关系。

**单变量排序的坑**：高 BM 组可能恰好全是小盘股（混入市值因素）。解法：

- **独立双重排序（交叉法）**：市值和 BM 各自分 5 组，取交集 25 个组合，组内做差价再平均；
- **条件双重排序（分层法）**：先按市值分 5 层，每层内再按 BM 分 5 组——市值被“控制住”了；
- 学术惯例：FF3 用 2×3（市值 2 档 × BM 3 档）。

>
> ⚠️ 数据说明：日线价格是真实的；估值只有一期快照，notebook 用价格路径推导了一个**教学用月度估值面板**。收益大小仅用于演示方法，不代表真实 A 股结论。

## 2.2 三种回归 —— 🏥“体检报告”

排序法算出了因子收益，但**多因子模型整体对不对**？用回归体检。

### ① 时序回归（先查每人敏感度）

```
r_it = α_i + β_i' f_t + ε_it
```

- 每个 β = 资产对因子的**敏感度**；
- α = 体检查不出的“隐藏问题”（定价误差）；
- 因子收益率时序已知（排序法给的），所以适合风格因子。

### ② 截面回归（两步）

先时序求 β，再拿“平均收益 ~ β”做截面回归：

```
mean(R_i) = λ' β_i + α_i
```

- 斜率 = 因子溢价 **λ**（线的斜率就是因子身价）；
- 每个点到线的距离 = **α**；
- 要 **Shanken 修正**：β 是估计值，不是真实值，直接当解释变量会带来 EIV 误差，标准误需要修正（2.2.2 节）。

### ③ Fama-MacBeth（先回归，再均值）—— ⭐必考

- 普通截面：把 T 期数据揉成一坨回归一次；
- FM：**每一期单独回归一次**，得到 T 个 λ_t，再平均；
- 妙处：绕开“截面相关性让标准误失真”的统计幻觉；
- 口诀：**截面回归 = 先均值再回归；FM = 先回归再均值。**

FM 的标准误通常再用 Newey-West 修正（见 2.4）。

| 方法 | 求什么 | 优点 | 注意 |
|---|---|---|---|
| 时序回归 | β（敏感度） | 直观、逐资产 | 需要因子收益时序 |
| 截面回归 | λ（因子溢价） | 直接估计身价 | β 是估计值，需 Shanken 修正 |
| FM 回归 | λ + 标准误 | 抗截面相关，业界标配 | 对时序相关无能为力，需 NW/GMM |

> 🐍 notebook 02.2 会先造一个“已知真相”的世界：预设 β 和 λ，看三种方法能不能把真相挖回来。

## 2.3 因子暴露：📏“用标签”比“猜性格”更准

- 老办法：时序回归“猜”β（通过行为猜性格，误差大）；
- 新办法：直接用**公司特征**（BM 高就是价值股、市值小就是小盘股）当暴露；
- Jegadeesh et al. (2019) 实证：**公司特征完胜**——用特征当暴露的因子被定价，用时序 β 的却没有；
- Fama-French (2020) 结论：**“截面回归多因子模型”（特征当暴露）优于传统“时序回归多因子模型”**。Barra 就是特征派。

> 一句话：能用“标签”（BM、市值、动量）时，优先用标签；不要什么都靠时序回归去猜。

## 2.4 异象检验 + Newey-West —— 🕶️“修正眼镜”

**检验异象**：异象组合收益对多因子模型回归，α 显著 ≠ 0 → 异象成立。

**但残差不乖**：时大时小（异方差）+ 今天影响明天（自相关）→ 普通标准误“隔着雾看东西”。

- **White 眼镜**：只修异方差；
- **Newey-West 眼镜**：两个毛病一起修（Bartlett 核权重，滞后越大权重越小）。

论文里“经 NW 调整后的 t 值”= 戴了修正眼镜的结果，更可信。

```
NW 协方差 = (X'X)^(-1) [ Σ_t e_t^2 x_t x_t' + Σ_j w_j (自协方差项) ] (X'X)^(-1)
w_j = 1 − j/(L+1)   （Bartlett 核）
```

> 🐍 notebook 02.3 会对比 OLS t 与 NW t，并展示“假阳性”为什么会出现。

## 2.5 比较多因子模型 —— 📝“两个老师改卷，比谁压分少”

- **GRS 检验**：把所有测试资产的 α 打包联合检验“是否一起为零”——有限样本精确 F 分布，学界首选；
- **均值-方差张成**：模型 A 的因子组合能否“覆盖”模型 B 的机会集；
- **α 检验**：逐个资产单独查（单科复核）；
- **贝叶斯方法**：先验 + 数据结合判断。

GRS 的原假设：

```
H0: α_1 = α_2 = ... = α_N = 0
```

p 值大 → 不能拒绝“所有 α 为零” → 模型通过体检；p 值小 → 模型解释不了某些收益 → 模型不够好。

> ⚠️ GRS 只回答“联合是否为零”，不指出“哪个资产”有问题；定位问题资产还需要逐个 α 检验。

## 2.6 正交化 —— 🗣️“只听增量信息”

“我今天吃了火锅” + “我吃了**辣的**火锅”——第二句没有增量。

正交化：把因子 B 对因子 A 回归，**残差 = B 的纯新增信息**。

```
B = β·A + ε
正交化后的 B = ε
```

- 残差与 A 不相关，所以不再重复计算 A 的信息；
- 业界构建因子组合前的常规操作；
- 注意：正交化的顺序会影响结果（先剔除谁，谁就保留更多原始信息）。

## 2.7 GMM —— 🧮“万能账本核对法”

三步：

1. **记账规则**（矩条件）：价格 = 未来收益折现，账必须平；
2. **拿数据对账**：找让账最平的参数；
3. **查账**：账不平的部分是运气还是模型错？

核心只有两件事：**样本均值的方差** + **delta 方法**（泰勒展开）。

- 权重 W = S⁻¹ 给“更靠谱的账”更高权重（有效估计）；
- ⚠️ 别当黑箱：从金融含义选权重，别只追统计最优。

## 2.8 研究方法建议 —— 🧭“套路总结”

| 研究问题 | 标准套路 |
|---|---|
| 检验异象 | 单变量排序 → 与市值双重排序 → 时序回归看 α → FM 加控制变量 |
| 检验因子 | 金融学依据 → 排序法 t 显著 → FM 佐证 |
| 比较模型 | 同一组测试资产：GRS + α 检验；互检因子：GRS + 均值方差张成 |
