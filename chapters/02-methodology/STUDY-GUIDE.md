## 2.1 排序法：分班考试（02.1）

### 2.1.0 为什么需要排序法？

第 1 章说：E[R] = βλ + α。  
但这里有个“先有鸡还是先有蛋”的问题：

- 想知道 λ，需要知道 β；
- 想知道 β，又需要知道因子收益；
- 但因子收益本身还没算出来。

排序法的聪明之处：**不猜 β，直接用“排序变量”代替“暴露”。**

> 你不需要知道每个学生“体质”多少，只需要按身高排队——高个子班 vs 矮个子班，比成绩就行了。

### 2.1.1 三步走：排队、分班、比赛

1. **排队**：用排序变量（比如 BM）把股票从高到低排；
2. **分班**：切成 10 组（惯例 L=10）；
3. **比赛**：高组收益 − 低组收益 = **价差组合收益 = 因子收益率**。

公式：

```
价差组合收益_t = R_high,t − R_low,t
```

**说人话**：

- 高 BM 组 = 便宜股；低 BM 组 = 贵股；
- 做多便宜股、做空贵股；
- 这个多空组合的收益，就是“价值因子”的收益率。

### 2.1.2 两个检验：显著性和单调性

**① t 检验**：这个分差是“真实力”还是“运气”？

- |t| > 2：95% 置信下显著；
- |t| ≤ 2：不能排除运气。

**② 单调性**：组号越高，收益是不是越高？

- Spearman 秩相关 ≈ +1：完美单调上升；
- ≈ −1：完美单调下降；
- 接近 0：没有明显单调关系。

> 单调性好，说明“排序变量”和“收益”不是偶然一两个组的关系，而是整体趋势。

### 2.1.3 单变量排序的坑：高 BM 可能只是小盘股

高 BM 组可能恰好全是小盘股。这样价差组合里，混入了“规模因子”的收益。

解法：**双重排序**。

- **独立双重排序（交叉法）**：市值分 5 组、BM 分 5 组，取交集 25 个组合；
- **条件双重排序（分层法）**：先按市值分 5 层，每层内再按 BM 分 5 组——市值被“控制住”了。

**说人话**：

> 先按身高分层，再在每一层里比体重。这样“身高”就不会混进“体重”的比较里。

### 2.1.4 Notebook 实战：02.1 到底算出了什么？

数据：

- 87 只 A 股，保留 81 只完整样本；
- 83 个月（2018-02 到 2024-12）；
- 日线价格真实，估值是“快照 + 价格路径”推导的教学面板。

**单变量排序（按 BM 分 10 组）**：

- Spearman 秩相关：**−0.842**；
- 组均收益：第 1 组 1.92%，第 10 组 0.12%（大致从高到低）。

**价差组合（高 BM − 低 BM）**：

- 月均收益：**−1.800%**；
- Newey-West t：**−2.28**；
- 结论：在这个教学面板上，价值因子是**显著负向**的。

> ⚠️ 这不是说“价值因子在 A 股一定无效”。这是教学合成估值面板的结果，只用于演示方法。讲义里已反复标注：**不要拿它当真实 A 股结论**。

**双重排序（先市值 5 层，层内再 BM 5 组）**：

| 市值层 | BM 价差（月均） |
|---|---|
| 第 1 层（小） | −1.139% |
| 第 2 层 | −2.223% |
| 第 3 层 | −1.766% |
| 第 4 层 | −0.698% |
| 第 5 层（大） | −0.570% |
| 五层平均 | −1.279% |

**怎么读**：

- 每一层内，BM 价差都是负的；
- 说明“价值因子为负”不是被市值混进来的；
- 但方向仍然是负的——这是教学面板的特性。

**记忆钩子**：

> 排序法 = 分班考试；价差 = 高组减低组；单调性 = 成绩跟不跟着排队走；双重排序 = 先分层，再比较。

### 2.1.5 本课记忆卡

- 排序法绕开了“β 未知”的循环：**变量高低 ≈ 暴露高低**。
- 价差组合 = 因子收益率。
- t 检验看显著性，Spearman 看单调性。
- 双重排序控制混淆因子（如市值）。
- 示例数据是教学面板，收益大小不代表真实 A 股。

## 2.2 三种回归：体检报告（02.2）

排序法算出了因子收益，但**多因子模型整体对不对**？用回归体检。

### 2.2.1 时序回归：查每个资产的“敏感度”

公式：

```
r_it = α_i + β_i' f_t + ε_it
```

**说人话**：

- 把每个资产，对一组因子做回归；
- β = 它对每个因子的敏感度；
- α = 回归解释不了的“体检异常”。

**什么时候用**：因子收益时序已知（比如风格因子），想知道每个资产对因子的暴露。

### 2.2.2 截面回归：查“市场为哪类风险付钱”

两步：

1. 先做时序回归，估出每个资产的 β；
2. 再拿“平均收益 ~ β”做截面回归。

公式：

```
mean(R_i) = λ' β_i + α_i
```

**说人话**：

- 横轴是 β，纵轴是平均收益；
- 斜率就是 λ（因子溢价）；
- 每个点到回归线的距离，就是 α。

**为什么需要 Shanken 修正？**

因为第一步估出来的 β 不是“真值”，是“估计值”。拿估计值当解释变量，会带来误差（EIV 问题），标准误需要修正。  
**说人话**：体检指标本身有测量误差，不修正就会高估“显著性”。

### 2.2.3 Fama-MacBeth：先回归，再平均

- 普通截面：把 T 期数据揉成一坨，回归一次；
- FM：**每一期单独回归一次**，得到 T 个 λ_t，再平均。

口诀：

> **截面回归 = 先均值再回归；FM = 先回归再均值。**

**为什么 FM 抗截面相关？**

因为每一期单独回归，λ_t 是“每期一个”，再对 λ_t 求平均和标准误；不会把不同期之间的截面相关性揉进一个标准误里。

**代价**：FM 对“时序相关”无能为力，所以标准误通常再用 Newey-West 修正。

### 2.2.4 Notebook 实战：02.2 怎么验证“已知真相”？

Notebook 先造了一个“上帝视角”的世界：

- 200 个资产、240 期、3 个因子；
- 预设真实 λ = [0.00881, 0.00804, 0.00469]；
- 预设每个资产的 β；
- 加噪声生成收益。

**① 时序回归：恢复 β**

- β 恢复最大误差：**0.12111**；
- 为什么不是 0？因为有噪声，而且这是 200×3=600 个系数里的“最大误差”，0.12 已经不算大。

**② 截面回归：恢复 λ**

| 因子 | 截面回归 λ | 真相 λ | 误差 |
|---|---|---|---|
| F1 | 0.00874 | 0.00881 | −0.00007 |
| F2 | 0.00820 | 0.00804 | +0.00016 |
| F3 | 0.00460 | 0.00469 | −0.00009 |

误差都在 1e-4 量级，说明**截面回归能恢复 λ**。

**③ FM：恢复 λ + 标准误**

| 因子 | FM λ | 真相 λ | 标准误 | t 值 |
|---|---|---|---|---|
| F1 | 0.0087 | 0.0088 | 0.0011 | 7.75 |
| F2 | 0.0080 | 0.0080 | 0.0014 | 5.84 |
| F3 | 0.0045 | 0.0047 | 0.0013 | 3.35 |

三个因子 |t| > 2，全部显著；FM 恢复的 λ 和真相几乎一致。

**④ 上 A 股快照：FM 检验价值/规模/动量**

| 特征 | λ | 标准误 | t 值 |
|---|---|---|---|
| 价值（BM） | −0.0040 | 0.0022 | −1.84 |
| 规模（ln 市值） | +0.0039 | 0.0021 | +1.84 |
| 动量 | +0.0029 | 0.0028 | +1.02 |

**怎么读**：

- 三个 t 值都不到 2，说明在这个教学面板上都不显著；
- 符号和大小只用于演示，不代表真实 A 股结论；
- 重点看流程：特征 → z-score → FM → λ/t 表。

### 2.2.5 本课记忆卡

- 时序回归：求 β、α。
- 截面回归：求 λ；β 是估计值，要 Shanken 修正。
- FM：每期回归再平均；抗截面相关；标准误再用 NW。
- 口诀：**截面 = 先均值再回归；FM = 先回归再均值。**
- 已知真相验证：β 误差 0.12、λ 误差 1e-4、t 值 7.75/5.84/3.35。

## 2.3 因子暴露：用标签，不猜性格

### 2.3.1 两种估 β 的方法

| 方法 | 怎么做 | 问题 |
|---|---|---|
| 时序回归 | 用资产收益对因子收益回归，估 β | β 是“猜”出来的，误差大 |
| 公司特征 | 直接用 BM、市值、动量等特征当暴露 | 更稳定、更可解释 |

**说人话**：

- 时序回归像“通过行为猜性格”：看一个人做什么，猜他是什么样的人；
- 特征法像“直接看标签”：BM 高就是价值股，市值小就是小盘股。

### 2.3.2 学术界的选择

- Jegadeesh et al. (2019)：**公司特征完胜**——用特征当暴露的因子被定价，用时序 β 的却没有；
- Fama-French (2020)：**“截面回归多因子模型”（特征当暴露）优于传统“时序回归多因子模型”**；
- Barra 风险模型，就是典型的“特征派”。

**记忆钩子**：

> 能用标签（BM、市值、动量），就别靠时序 β 猜性格。

> 🐍 02.2 的 A 股 FM 部分，用的就是特征（BM、ln 市值、动量）做 z-score，而不是时序 β。

## 2.4 异象检验 + Newey-West：修正眼镜（02.3 前半）

### 2.4.1 怎么检验一个异象？

做法：

1. 构建异象组合（比如高 F-Score 减低 F-Score）；
2. 把组合收益对多因子模型回归；
3. 看 α 是否显著不等于 0。

**说人话**：

> 模型说这个组合应该赚多少；实际赚了多少；多出来的部分（α）如果显著，就说明模型解释不了它——这就是异象。

### 2.4.2 残差的两个毛病

- **异方差**：有时波动大，有时波动小；
- **自相关**：今天的影响明天还在。

普通 OLS 标准误假设残差“同方差、不相关”，所以会“隔着雾看东西”。

**三种眼镜**：

| 方法 | 修正什么 |
|---|---|
| OLS | 什么都不修（假设最理想） |
| White | 只修异方差 |
| Newey-West | 异方差 + 自相关一起修 |

**NW 的直觉**：

- 不只加“当期残差平方”，还加“相邻期的协方差”；
- 滞后越远，权重越小（Bartlett 核）；
- 这样标准误更接近真实，t 值更可信。

### 2.4.3 Notebook 实战：02.3 的异象检验

Notebook 造了 8 个资产、3 个因子，给资产 0 注入 **0.8%/月** 的真实 α。

输出：

| 资产 | α 估计（%/月） | OLS t | NW t | 真相 α（%/月） |
|---|---|---|---|---|
| a0 | 0.737 | 11.548 | 12.115 | 0.8 |
| a1 | 0.039 | 0.565 | 0.622 | 0.0 |
| a2 | −0.037 | −0.556 | −0.559 | 0.0 |
| a3 | 0.067 | 1.066 | 1.084 | 0.0 |
| a4 | −0.016 | −0.238 | −0.258 | 0.0 |
| a5 | −0.165 | −2.295 | −2.293 | 0.0 |
| a6 | 0.156 | 2.354 | 2.387 | 0.0 |
| a7 | 0.028 | 0.374 | 0.327 | 0.0 |

**怎么读**：

- a0：α 估计 0.737%，接近真相 0.8%；NW t=12.1，非常显著；
- a1~a7：真实 α=0，但 a5、a6 的 |t| 略大于 2——这是**假阳性**；
- 本例 OLS 和 NW 很接近，因为模拟噪声是独立同分布的；真实数据里，NW 往往差别更大。

**重要提醒**：

> 逐个看 t 值，总会有假阳性。8 个资产里出现 1~2 个 |t|>2，很正常。  
> 所以不能只看单个 t 值，还要看 GRS 联合检验和多重检验校正。

### 2.4.4 本课记忆卡

- 异象检验 = 回归 α 显著 ≠ 0。
- 残差有异方差/自相关，普通 t 值会骗你。
- White 修异方差；NW 两个一起修。
- 本例：a0 α=0.737%，NW t=12.1；a5/a6 是假阳性。

## 2.5 GRS：集体体检（02.3 中段）

### 2.5.1 GRS 在做什么？

原假设：

```
H0: α_1 = α_2 = ... = α_N = 0
```

**说人话**：

> 把一群资产的 α 打包，问一句：它们是不是**一起**为零？

- p 值大：不能拒绝“全为零” → 模型通过体检；
- p 值小：拒绝 → 模型解释不了某些收益 → 模型不够好。

### 2.5.2 Notebook 实战：02.3 的 GRS

输出：

```
GRS F = 17.934, p 值 = 0.000000
p < 0.05 → 模型被拒绝：存在模型解释不了的异象
```

**怎么读**：

- 因为资产 0 被注入了 0.8%/月的真实 α，GRS 联合检验拒绝了“所有 α=0”；
- 这证明 GRS 能抓出“集体异常”；
- 但 GRS 只告诉你“有问题”，不告诉你“谁有问题”。

### 2.5.3 GRS 的三个注意点

1. **它不定位**：拒绝后，还要逐个看 α，找出问题资产；
2. **它看联合**：单个资产不显著，联合可能显著；反之亦然；
3. **它有功放问题**：样本短、资产少、因子多时，可能“无力拒绝”。

**记忆钩子**：

> GRS = 全班集体体检；p 小 = 班里有问题；但老师还得逐个问“谁不舒服”。

### 2.5.4 本课记忆卡

- GRS 原假设：所有 α 联合为零。
- p 大 = 通过；p 小 = 拒绝。
- GRS 不定位问题资产，要配合逐个 α 检验。
- 本例 GRS F=17.934，p≈0，模型被拒绝。

## 2.6 正交化：只听增量信息（02.3 后半）

### 2.6.1 火锅比喻

- “我今天吃了火锅。”
- “我今天吃了**辣的**火锅。”

第二句没有增量，因为“辣的”是“火锅”的一种。

**说人话**：

> 如果 B 的信息大部分已经包含在 A 里，那么 B 的“新增信息”就是：B 对 A 回归后的残差。

公式：

```
B = β·A + ε
正交化后的 B = ε
```

### 2.6.2 Notebook 实战：02.3 的正交化

Notebook 人为制造了两个高度相关的因子：

```
F3 = 0.9 × F2 + 噪声
```

输出：

```
正交化前 F2 与 F3 的相关系数: 0.8998
正交化后 F2 与 F3 的相关系数: 0.0000000000
```

**怎么读**：

- 正交化前，F2 和 F3 相关性 0.90，信息高度重叠；
- 把 F3 对 F2 回归，取残差；
- 残差与 F2 的相关性为 0——残差就是 F3 的“纯增量”。

### 2.6.3 正交化的三个注意点

1. **顺序很重要**：先剔除谁，谁就保留更多原始信息；反过来结果不同；
2. **不是所有因子都要正交化**：如果两个因子经济逻辑不同，强行正交化可能删掉有用信息；
3. **正交化后要重新检验**：残差因子是否还有溢价？是否还有经济意义？

**记忆钩子**：

> 正交化 = 把“重复的话”删掉，只留“新信息”。  
> 顺序不同，留下来的人也不同。

### 2.6.4 本课记忆卡

- 正交化：B 对 A 回归，残差 = B 的增量。
- 残差与 A 不相关。
- 顺序会影响结果。
- 本例：相关性 0.8998 → 0。

## 2.7 GMM：万能账本核对法

> 这一节没有 notebook 代码，但思想很重要。可以把它当成“所有检验方法的爷爷”。

### 2.7.1 三步：记账、对账、查账

1. **记账规则（矩条件）**：  
   比如“价格 = 未来收益折现”，账必须平。用数学写，就是一组矩条件 E[g(θ)] = 0。
2. **拿数据对账**：  
   找一组参数 θ，让样本矩尽量接近 0——这就是估计。
3. **查账**：  
   账不平的部分，是运气，还是模型错了？用过度识别检验判断。

### 2.7.2 核心只有两件事

- **样本均值的方差**：估计量准不准；
- **delta 方法**：非线性函数的方差，用泰勒展开近似。

**权重 W = S⁻¹**：

- S 是矩的协方差；
- 给“更靠谱的账”更高权重；
- 这就是“有效估计”。

### 2.7.3 为什么“别当黑箱”？

- GMM 可以塞进很多矩条件，但**矩条件必须有金融含义**；
- 权重选择会影响结果；
- 过度识别检验拒绝，不代表模型一定错，可能是某个矩条件不靠谱；
- 工具越万能，越需要知道它在干什么。

**记忆钩子**：

> GMM = 记账（矩条件）→ 对账（估参数）→ 查账（检验）。  
> 账本越万能，越要知道哪笔账是真的。

---

## 2.8 研究套路：三种常见问题怎么打？

| 研究问题 | 标准套路 |
|---|---|
| **检验异象** | 单变量排序 → 与市值双重排序 → 时序回归看 α → FM 加控制变量 |
| **检验因子** | 金融学依据 → 排序法 t 显著 → FM 佐证 |
| **比较模型** | 同一组测试资产：GRS + α 检验；互检因子：GRS + 均值方差张成 |

**说人话**：

- 检验异象：先看它是不是真的（排序），再看是不是被市值/行业混淆（双重排序），再看扣掉模型后 α 还在不在（时序/FM）；
- 检验因子：先讲经济逻辑，再看排序法显不显著，再用 FM 交叉验证；
- 比较模型：用同一套测试资产，比谁的 α 更小、GRS 更好；互相检验时看均值-方差张成。

## 2.9 全章串联：一张图记住第 2 章

```
原始数据
   │
   ├─ 排序法：排队 → 分组 → 高减低 = 因子收益
   │
   ├─ 时序回归：r = α + βf + ε → β（敏感度）、α（异常）
   │
   ├─ 截面回归：mean(R) = λβ + α → λ（因子价格）
   │
   ├─ FM：每期回归再平均 → λ + 标准误（抗截面相关）
   │
   ├─ NW：修异方差 + 自相关 → t 值更可信
   │
   ├─ GRS：一群 α 是否联合为零 → 模型体检
   │
   ├─ 正交化：残差 = 增量信息
   │
   └─ GMM：矩条件 = 记账规则 → 统一检验框架
```

**如果只记 5 句话**：

1. 排序法：变量高低 ≈ 暴露高低，价差组合 = 因子收益。
2. 时序求 β，截面求 λ，FM 先回归再平均。
3. NW 是修正眼镜，修异方差 + 自相关。
4. GRS 是集体体检，p 小 = 模型有问题，但不告诉你谁有问题。
5. 正交化：残差才是增量；GMM：记账、对账、查账。

## 2.10 自测题（先答，再看答案）

### Q1：排序法为什么能绕开“先有鸡还是先有蛋”的循环？

**答案**：

- 因为排序法不直接估计 β，而是用“排序变量”代替“暴露”；
- 假设“变量高低 ≈ 暴露高低”，先分组、再比较收益；
- 这样就不需要先知道因子收益，也能算出因子收益。

### Q2：时序回归、截面回归、FM 各求什么？口诀是什么？

**答案**：

- 时序回归：求 β（敏感度）和 α；
- 截面回归：求 λ（因子溢价）；
- FM：每期回归再平均，求 λ + 标准误；
- 口诀：**截面 = 先均值再回归；FM = 先回归再均值。**

### Q3：为什么截面回归需要 Shanken 修正？

**答案**：

- 因为第一步估出的 β 是“估计值”，不是真实值；
- 拿估计值当解释变量，会带来 EIV 误差；
- Shanken 修正调整标准误，避免高估显著性。

### Q4：Newey-West 修正哪两个问题？为什么说它是“眼镜”？

**答案**：

- 修正异方差和自相关；
- 普通 OLS 标准误假设残差同方差、不相关，现实往往不是；
- NW 用加权自协方差修正，让 t 值更接近真实，所以像“戴上修正眼镜”。

### Q5：为什么 02.3 里 a5、a6 的 |t|>2，但真实 α=0？

**答案**：

- 这是假阳性；5% 显著性水平下，本来就会有约 5% 的假阳性；
- 8 个资产里出现 1~2 个 |t|>2，很正常；
- 所以不能逐个看 t 值就下结论，还要看 GRS 和多重检验。

### Q6：GRS 的原假设是什么？p 值大说明什么？它有什么局限？

**答案**：

- H0：所有 α 联合为零；
- p 值大：不能拒绝，模型通过体检；
- 局限：只回答“联合是否为零”，不指出哪个资产有问题；样本短/资产少时功效低。

### Q7：正交化里的“残差”代表什么？为什么顺序重要？

**答案**：

- 残差 = B 中不能被 A 解释的“纯增量信息”；
- 顺序决定“谁被剔除、谁保留原始信息”：B 对 A 回归保留 B 的增量；反过来保留 A 的增量，结果不同。

### Q8：GMM 的三步是什么？为什么“别当黑箱”？

**答案**：

- 记账（矩条件）→ 对账（估参数）→ 查账（检验）；
- 矩条件和权重都要有金融含义；工具越万能，越容易掩盖假设和模型错误。

### Q9：一个因子 t=2.5，但 GRS p=0.6，怎么解释？

**答案**：

- 单个因子看似显著，但联合检验不显著；
- 可能是多重检验下的假阳性，也可能是 GRS 功效低；
- 不能只凭 t=2.5 就下结论，要看经济逻辑、样本外、其他因子/模型。

## 2.11 七个最容易混淆的点

| 容易混淆 | 正确理解 |
|---|---|
| 排序法 = 因果证明 | 排序法只找“伴随关系”，不证明因果；混淆因子要靠双重排序/FM 控制 |
| 价差组合 = 因子收益 | 价差组合是因子收益的**代理**，取决于排序变量、分组数、加权方式 |
| t=2 = 真理 | 多重检验下 t=2 不够；还有假阳性、样本外、经济逻辑 |
| 时序 β = 特征暴露 | 特征通常更稳、更可解释；时序 β 是“猜”的 |
| 截面回归 = FM | 截面是先均值再回归；FM 是先回归再均值 |
| GRS 拒绝 = 知道谁有问题 | GRS 只告诉你“集体有问题”，定位要靠逐个 α |
| GMM = 黑箱 | GMM 是“记账规则 + 对账 + 查账”，假设和权重都要能解释 |
