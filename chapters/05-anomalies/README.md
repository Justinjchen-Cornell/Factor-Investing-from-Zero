## 📖 5.1 F-Score：九信号财务体检（Piotroski 2000）

**核心思想**：同样是“便宜股”，有的能翻身，有的是价值陷阱。F-Score 用 9 个财务信号给公司做体检：

| # | 信号 | 含义 | 1 分条件 |
|---|---|---|---|
| 1 | ROA | 盈利能力 | ROA > 0 |
| 2 | CFO | 经营现金流 | CFO > 0 |
| 3 | ΔROA | 盈利改善 | ΔROA > 0 |
| 4 | 应计质量 | 利润有现金流支撑 | CFO > ROA |
| 5 | ΔLeverage | 杠杆下降 | ΔLeverage < 0 |
| 6 | ΔCurrent ratio | 流动性改善 | ΔCurrent ratio > 0 |
| 7 | 增发 | 没有稀释股东 | 没有增发（equity issued ≤ 0） |
| 8 | ΔGross margin | 毛利率改善 | ΔGross margin > 0 |
| 9 | ΔAsset turnover | 周转率改善 | ΔAsset turnover > 0 |

**经典用法**：在高 BM（便宜）股票池里，做多高 F-Score、做空低 F-Score，检验“财务健康”能否区分好公司与价值陷阱。

**相关分数**：
- **G-Score（Mohanram 2005）**：面向成长股的 8 信号评分；
- **预期差**：盈余公告后的惊喜（earnings surprise）与漂移（PEAD）。

> ⚠️ 本仓库没有完整财报，notebook 的 F-Score 九项信号由**教学合成财务面板**生成；只演示计算与排序流程，不代表真实公司财务。

## 5.2 基本面锚定反转

### ① 52 周高点锚定

**构造**：

```
proximity_t = P_t / max(P_{t-11}, ..., P_t)
```

- 接近 1：价格贴近 52 周高点；
- 接近 0：价格离高点很远。

**经济逻辑**：
- **锚定效应**：投资者把 52 周高点当作“参考价”，靠近高点时过度乐观，远离高点时过度悲观；
- **过度反应**：价格偏离基本面后，未来可能反转；
- **处置效应**：投资者不愿卖亏损股，导致价格调整不充分。

**实证方向**：靠近高点的股票未来可能跑输，远离高点的股票可能跑赢（反转）。但结果依赖样本、窗口和市场。

### ② 长期反转

**构造**：过去 36 个月累计收益（跳过最近 1 个月），做多输家、做空赢家。

**经济逻辑**：
- 过度反应 → 长期赢家被高估、输家被低估 → 未来反转；
- 与动量（12-1）方向相反：短期动量、长期反转，时间尺度不同。

> ⚠️ 本仓库用真实价格快照（87 只股票，2018-2024）演示；样本小、区间短，结果不代表真实 A 股。

## 5.3 特质波动率（IVOL）

**构造**：

1. 对每只股票做多因子时序回归：$r_{it} = \alpha_i + \beta_i' f_t + \varepsilon_{it}$；
2. 取残差 $\varepsilon_{it}$ 的滚动标准差（通常 24 个月），年化；
3. 按 IVOL 排序，做多低 IVOL、做空高 IVOL。

**经济逻辑与谜题**：
- 传统金融：高风险应该高收益；
- 实证谜题：**高 IVOL 股票的未来收益往往更低**（IVOL 负相关）；
- 解释：**套利限制 + 投资者偏好彩票型股票** → 高 IVOL 被高估；
- **套利不对称**：高 IVOL 股票做空成本高/限制多，错误定价更难被纠正。

> ⚠️ IVOL 使用真实价格 + 第3章因子（部分因子为教学面板）；样本仅 87 只股票。notebook 的结果可能和经典 IVOL 之谜相反，这正说明异象对样本/窗口/因子模型敏感。

## 5.4 研究异象的建议

1. **先有经济逻辑**：风险补偿、行为偏差、还是数据窥探？
2. **数据要干净**：ST/退市/次新股/涨跌停/缩尾；
3. **多重检验**：试了很多异象，总有几个“显著”；提高 t 阈值或做样本外；
4. **稳健性**：换窗口、换分组、换因子模型、分区间；
5. **交易成本**：高换手异象可能被成本吃掉；
6. **不要外推**：小样本/合成数据的结果不能直接当真实市场结论。
