## 📖 7.1 收益率模型 vs 风险模型

| 模型 | 回答的问题 | 输出 |
|---|---|---|
| **收益率模型** | 预期收益从哪里来？ | 因子溢价、α、预测变量 |
| **风险模型** | 组合波动/相关性从哪里来？ | 协方差矩阵、因子暴露、特质风险 |

**收益率模型**（原书 7.1 节）：

```
E[R_i] = β_i' λ + α_i
```

- 因子溢价 λ 是“收益的来源”；
- α 是模型解释不了的超额收益；
- 预测变量筛选要避免数据窥探、前视偏差。

**风险模型**（原书 7.2 节）：

```
Σ = B Σ_f B' + D
```

- B：股票对因子的暴露；
- Σ_f：因子协方差；
- D：特质风险（对角矩阵）。

> 收益率模型和风险模型是两套模型：**收益模型错，组合会偏；风险模型错，组合会“假分散”。**

## 7.2 Barra 风险模型：业界标准

Barra（现 MSCI）风险模型的核心结构：

- **1 个国家因子**（中国市场）；
- **9 个风格因子**（Size、Value、Momentum、Quality、Growth、Leverage、Liquidity、Volatility、Dividend Yield 等，CNE6 口径）；
- **行业因子**（30+ 个行业）；
- **特质风险**（股票特有）。

**纯因子组合（pure factor portfolio）**：对某个因子暴露为 1、对其他因子暴露为 0 的组合；用横截面回归估计因子收益。

**特征值调整（eigenfactor adjustment）**：因子协方差矩阵可能低估/高估某些风险方向，Barra 用特征值调整让风险预测更稳。

> 本仓库没有行业分类和 Barra 因子数据；notebook 用 7 个风格因子做一个**迷你风险模型**，演示“暴露 → 协方差 → 优化 → 归因”的流程。

## 7.3 组合优化：均值-方差与“误差最大化”

**均值-方差优化**：

```
max_w  w'μ − λ/2 · w'Σw
s.t.   Σ w_i = 1,  w_i ≥ 0,  w_i ≤ cap
```

- μ：预期收益（来自收益率模型）；
- Σ：协方差（来自风险模型）；
- λ：风险厌恶系数；
- 约束：长仓、权重上限、行业/因子暴露限制、换手约束。

**“误差最大化器”**：优化器会放大预期收益的估计误差——μ 稍微估错，权重就会极端集中。  
所以实践中：

1. 预期收益要**收缩/稳健化**（shrinkage、因子模型、贝叶斯）；
2. 加约束（权重上限、行业中性、换手限制）；
3. 风险模型比收益模型更可靠，但也会错；
4. 对比等权/风险平价等“笨办法”，别迷信优化。

> 🐍 notebook 07.1：用迷你风险模型做最小方差/最大 Sharpe 组合，并展示风险归因。
> 07.4 会看到：风险模型估计的总波动（约 70%）远高于回测波动（约 20%）——**风险模型错位**是实践中的大问题。

## 7.4 Smart Beta：把因子做成产品

**Smart Beta** = 用规则化的因子暴露构建指数/ETF，介于被动和主动之间。

**常见加权方式**：

| 方式 | 权重 | 特点 |
|---|---|---|
| 等权 | 1/N | 简单、分散、换手较低 |
| 市值加权 | 市值 | 容量大、偏向大市值 |
| 分数加权 | 因子分数 | 暴露更强、集中度更高 |
| 风险加权 | 1/vol | 风险平价思想、降低高波动股权重 |

**构建流程**：

1. 选因子（价值/质量/动量/低波/低换手…）；
2. 合成复合分数（z-score 加权）；
3. 选股（top 20%/30%）；
4. 加权（等权/分数/风险）；
5. 定期调仓、扣交易成本。

> 🐍 notebook 07.2：复合分数 = 价值 + 质量 + 动量 − 换手 − 投资；比较等权/分数加权/基准。

## 7.5 因子择时：很难

**常见信号**：

- **估值**：因子相对估值处于历史低位 → 预期未来收益高；
- **动量**：因子近期表现好 → 可能延续；
- **波动/拥挤**：因子波动/资金流入过高 → 可能反转；
- **情绪/宏观**：利率、信用利差、经济周期。

**为什么难**：

- 因子收益的信噪比低，择时信号更容易过拟合；
- 宏观变量滞后、样本短；
- 择时增加换手和交易成本；
- “这次不一样”经常发生。

> 🐍 notebook 07.2 用 12 个月趋势信号做简单择时，结果因因子而异——**择时不是稳定印钞机**。

## 7.6 风格分析：Sharpe 回归

Sharpe (1992) 的**收益-based 风格分析**：

```
r_p = α + β_MKT·MKT + β_SMB·SMB + β_HML·HML + ... + ε
```

- β 反映组合/基金在风格因子上的暴露；
- R² 反映因子能解释多少收益；
- α 是因子解释不了的超额收益。

**用途**：

- 基金风格漂移监测；
- 组合归因；
- 判断一个“主动基金”是不是只是因子暴露的打包。

> 🐍 notebook 07.3 构造一个“假装是基金”的组合，用回归反推 0.6/0.2/0.1/0.1 的真实暴露。

## 7.7 风险归因与业绩归因

**风险归因**（Euler 分解）：

```
总方差 = 因子方差 + 特质方差
总波动 = Σ 因子风险贡献 + 特质风险贡献
```

- 因子贡献：组合在因子上的暴露 × 因子协方差；
- 特质贡献：组合的特质风险；
- 贡献之和 = 总波动。

**业绩归因**：

```
组合收益 = Σ 因子暴露 × 因子收益 + α
```

- 因子贡献：选对风格/因子带来的收益；
- α：模型解释不了的收益（选股/交易能力，也可能是运气/模型错位）。

> 归因是“解释”，不是“预测”。模型不同，归因结果不同；看到漂亮 α 先怀疑模型。

## 7.8 另类数据与大类资产配置

**另类数据**：舆情、卫星、招聘、专利、供应链、信用卡消费、App 使用等。

- 价值：信息优势、低相关性；
- 难点：数据清洗、时点、覆盖率、合规、成本；
- 原则：先问“它为什么能预测收益”，再问“数据质量够不够”。

**因子大类资产配置**：把价值/动量/ carry/防御等因子应用到股票、债券、商品、外汇等多资产；注意不同资产的因子定义和风险不同。
