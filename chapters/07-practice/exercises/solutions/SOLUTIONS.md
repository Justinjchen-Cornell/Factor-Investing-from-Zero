# 第7章 练习参考答案

## 练习 1

1. 收益率模型回答“预期收益从哪里来”（因子溢价、α）；风险模型回答“组合波动/相关性从哪里来”（协方差、因子暴露、特质风险）。
2. 预期收益是“方向/大小”，风险是“不确定性”；高预期收益可能伴随高风险，两者不能混为一谈。
3. 收益模型错、风险模型对：组合可能偏离最优，但风险控制还行；收益模型对、风险模型错：可能“假分散”，实际风险远超预期。

## 练习 2

1. 国家因子 + 风格因子 + 行业因子 + 特质风险。
2. 对某个因子暴露为 1、对其他因子暴露为 0 的组合；用于估计纯因子收益。
3. 因子协方差矩阵可能低估/高估某些风险方向；特征值调整让风险预测更稳健（避免组合在某个方向上过度集中）。

## 练习 3

1. 优化器会利用估计误差：μ 稍微高估，权重就会极端集中；Σ 的误差也会被利用。
2. **μ 的误差更危险**：目标函数对 μ 是线性的，对 Σ 是二次的；μ 的小误差会直接放大权重。
3. 收缩/稳健估计、加约束（权重上限、行业中性、换手限制）、风险平价/等权基准、样本外检验、交易成本。

## 练习 4

- **等权**：1/N；简单、分散、换手较低；可能偏离因子暴露；适合不想承担集中风险的投资者。
- **分数加权**：按因子分数；暴露更强；集中度高、换手/容量压力大；适合研究/高信念组合。
- **风险加权**：1/vol；降低高波动股权重；可能引入低波因子暴露；适合风险预算/风险平价思路。

## 练习 5

1. 因子收益信噪比低、样本短、非平稳；择时信号容易过拟合；交易成本/换手高。
2. 估值（历史分位）、动量（趋势）、波动/拥挤、情绪、宏观；问题：信号噪声大、样本短、滞后、参数敏感。
3. 预注册、样本外/滚动检验、限制参数数量、扣交易成本、多因子/多信号组合、经济逻辑。

## 练习 6

1. 高 MKT、较高 SMB、较高 HML → 偏**小盘价值**风格。
2. R² = 0.91：91% 的收益波动能被 FF3 解释，基金很像“风格打包”，主动选股空间小。
3. α 的 t = 0.8 < 2：没有显著的超额收益，不能证明基金经理有选股能力。

## 练习 7

1. 总方差 = 0.16² + 0.12² = 0.0256 + 0.0144 = **0.04**，总波动 = 20%，自洽。
2. 因子风险贡献 = 0.0256 / 0.20 = **12.8%**；特质风险贡献 = 0.0144 / 0.20 = **7.2%**。
3. 12.8% + 7.2% = **20%**，等于总波动（Euler 分解）。

## 练习 8

可能原因：

1. **前视偏差**：用了当时不可得的数据（财报滞后、未来信息）；
2. **幸存者偏差**：只保留现在还在的股票；
3. **数据窥探/过拟合**：试了很多因子/参数，只挑好看的结果；
4. **忽略交易成本/冲击/容量**：高换手策略实盘被成本吃掉；
5. **样本特定/非平稳**：只在某段区间有效，市场结构变了；
6. **公司行动/复权错误**：分红、拆股、停牌处理不当；
7. **选择偏差**：只报告成功策略，不报告失败尝试。

避免：point-in-time 数据、全样本/退市股票、预注册、样本外、扣成本、稳健性、容量分析。
