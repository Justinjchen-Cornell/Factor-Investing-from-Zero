## 📖 3.1 数据处理：因子研究的第一道关

原书 3.1 节的处理流程（A 股惯例）：

1. **月度调仓**：用月末收盘价计算月度收益；
2. **剔除特殊样本**：ST/*ST、退市、负净资产、次新股（上市不足 6~12 个月）；
3. **缩尾**：对因子值做 1%/99% 缩尾，防止极端值主导分组；
4. **剔除一字涨跌停**：避免“看得见、买不到”的虚假收益；
5. **保留金融股**：银行/券商/保险不剔除（是否剔除取决于研究问题）；
6. **对齐**：因子值用 t 期（或 t 期之前已知的信息），收益用 t+1 期，避免未来函数。

> ⚠️ **本仓库的数据限制**：示例数据只有 87 只股票的日线快照 + 一期估值快照，无法完整执行 ST/次新股/涨跌停过滤。Notebook 保留完整历史的 81 只股票，并在因子层面做极端值裁剪。真实研究请按原书流程补齐。

## 3.2 市场因子（MKT）

**构造**：市值加权市场组合收益（通常再减去无风险利率，得到超额收益）。

```
MKT_t = Σ_i w_it · r_it,   w_it = 市值权重
```

**经济逻辑**：市场因子代表**系统性风险**。股票对市场的敏感度（β）越高，要求的风险补偿越高（CAPM）。

**A 股实证（原书口径）**：市场因子是其他因子定价检验的**基准**；但在多因子模型中，市场因子的显著性取决于模型设定与样本区间，原书 A 股多元模型里市场因子并不一定显著。不要把“市场重要”直接等同于“MKT 的 t 值一定很大”。

## 3.3 规模因子（SMB）

**构造**：按市值排序，做多小市值、做空大市值。

```
SMB = R_small − R_big
```

**经济逻辑**：
- 风险补偿：小公司经营风险、流动性风险更高；
- 行为解释：小盘股容易被散户追逐、被情绪推高；
- 但也可能只是“流动性溢价”或“壳价值”。

**A 股实证（原书口径）**：规模因子在 A 股长期被定价，小市值有溢价；但 2017 年以后明显减弱，波动和回撤都很大。**不能把“小盘”当成稳赚。**

## 3.4 价值因子（HML）

**构造**：按 BM（账面市值比）排序，做多高 BM、做空低 BM；也可用 EP（盈利市值比）。

```
HML = R_highBM − R_lowBM
```

**经济逻辑**：
- 风险补偿：便宜股往往处于困境行业/公司，承担更高风险；
- 行为解释：投资者对坏消息过度反应，导致便宜股被低估；
- 价值陷阱：便宜可能是因为基本面在变坏，所以要结合质量因子。

**A 股实证（原书口径）**：价值因子在 A 股被定价，BM/EP 都有解释力；但价值策略会有长时间跑输的区间。

## 3.5 动量因子（WML）

**构造**：按过去 12 个月（跳过最近 1 个月）的累计收益排序，做多赢家、做空输家。

```
WML = R_winners − R_losers
```

**经济逻辑**：
- 行为解释：投资者对信息反应不足（underreaction），价格趋势会延续；
- 风险解释：动量崩溃（momentum crash）——市场反转时，赢家组合会剧烈回撤；
- A 股特殊性：散户占比高、反转效应强，动量在 A 股常常不显著，甚至方向相反。

**A 股实证（原书口径）**：动量因子在 A 股整体不显著，短期反转更常见；不能把美股的动量结论直接搬过来。

## 3.6 盈利因子（RMW）

**构造**：按盈利能力（ROE、ROA、毛利率等）排序，做多高盈利、做空低盈利。

```
RMW = R_highROE − R_lowROE
```

**经济逻辑**：
- 质量溢价：盈利能力强的公司更安全、现金流更稳；
- 错误定价：投资者可能低估“好公司”的持续性；
- 和价值因子互补：好公司 + 合理价格，才是“质量价值”。

**A 股实证（原书口径）**：盈利/质量因子在 A 股被定价，和价值的组合（质量价值）通常比单用价值更稳。

## 3.7 投资因子（CMA）

**构造**：按投资强度（总资产增长、资本开支增长等）排序，做多低投资（保守）、做空高投资（激进）。

```
CMA = R_lowInvestment − R_highInvestment
```

**经济逻辑**：
- 投资异象：高投资/高扩张的公司，未来收益往往更低（过度投资、 empire building）；
- 风险解释：投资多的公司可能承担更高风险，但市场未必给足补偿；
- 会计口径影响很大：用总资产增长还是资本开支，结果可能不同。

**A 股实证（原书口径）**：投资因子在 A 股整体不显著，且对口径敏感；不要把它当成稳定因子。

## 3.8 换手率因子（TURN）

**构造**：按换手率排序，做多低换手、做空高换手（A 股“低换手溢价”方向）。

```
TURN = R_lowTurnover − R_highTurnover
```

**经济逻辑**：
- 流动性/注意力：高换手往往伴随高关注、高情绪、高估值；
- 行为解释：过度自信、追涨杀跌，导致高换手股票未来收益更低；
- 交易成本：高换手策略本身也会被成本和冲击吃掉。

**A 股实证（原书口径）**：换手率在 A 股被显著定价（负向），是中国版三因子模型的重要成员（Liu et al. 2019）。

## 📋 本章小结

| 因子 | 构造 | 经济逻辑 | A 股实证（原书口径） |
|---|---|---|---|
| MKT 市场 | 市值加权市场收益 | 系统性风险补偿 | 定价基准；多因子模型中显著性取决于样本 |
| SMB 规模 | 小市值 − 大市值 | 小公司风险/流动性/情绪 | 长期被定价，近年减弱、波动大 |
| HML 价值 | 高 BM − 低 BM | 困境风险/过度反应 | 被定价，会有长期跑输区间 |
| WML 动量 | 高动量 − 低动量 | 反应不足/趋势延续 | 整体不显著，短期反转更常见 |
| RMW 盈利 | 高 ROE − 低 ROE | 质量溢价/持续性被低估 | 被定价，常与价值互补 |
| CMA 投资 | 低投资 − 高投资 | 过度投资/投资异象 | 整体不显著，对口径敏感 |
| TURN 换手率 | 低换手 − 高换手 | 情绪/过度自信/交易成本 | 显著负向，中国版三因子成员 |
