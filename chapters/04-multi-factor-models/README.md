## 📖 4.1 多因子模型是什么？

单因子模型（CAPM）只用市场因子解释收益；多因子模型认为：

> 资产的预期收益，由它对**多个系统性风险**的暴露共同决定。

```
E[R_i] = β_i1 λ_1 + β_i2 λ_2 + ... + β_iK λ_K + α_i
```

- β：资产对每个因子的暴露；
- λ：每个因子的风险溢价；
- α：模型解释不了的定价误差。

一个好模型的标准：

1. **解释力**：平均 |α| 小、R² 高；
2. **显著性**：因子溢价显著（t 值大）；
3. **简约性**：因子少而精，不为了 R² 堆因子；
4. **经济逻辑**：因子有风险补偿或行为偏差的解释。

## 4.2 FF3：Fama-French 三因子（1993）

```
R_i − R_f = α_i + β_MKT·MKT + β_SMB·SMB + β_HML·HML + ε_i
```

- **MKT**：市场超额收益；
- **SMB**：小市值 − 大市值；
- **HML**：高 BM − 低 BM。

**贡献**：把 CAPM 解释不了的“规模效应”和“价值效应”收编成两个因子。  
**局限**：解释不了动量、盈利、投资等异象。

## 4.3 Carhart4：三因子 + 动量（1997）

```
R_i − R_f = α_i + β_MKT·MKT + β_SMB·SMB + β_HML·HML + β_WML·WML + ε_i
```

- **WML**：赢家 − 输家（12-1 动量）。

**贡献**：共同基金业绩归因的常用基准；把动量异象纳入模型。  
**局限**：动量在 A 股整体不显著，Carhart4 在 A 股的适用性要打问号。

## 4.4 NovyMarx4：市场 + 价值 + 动量 + 盈利（2013）

```
R_i − R_f = α_i + β_MKT·MKT + β_HML·HML + β_WML·WML + β_RMW·RMW + ε_i
```

- **RMW**：高盈利 − 低盈利（ROE/毛利率等）。
- 特点：不含 SMB，强调“质量 + 价值 + 动量”的组合。

**贡献**：把“盈利质量”引入定价模型，解释了部分价值股的超额收益。  
**局限**：因子定义和口径敏感，盈利指标的选择会影响结论。

## 4.5 FF5：Fama-French 五因子（2015）

```
R_i − R_f = α_i + β_MKT·MKT + β_SMB·SMB + β_HML·HML + β_RMW·RMW + β_CMA·CMA + ε_i
```

- **RMW**：高盈利 − 低盈利；
- **CMA**：低投资 − 高投资（保守 − 激进）。

**贡献**：在三因子上加入盈利和投资，解释力提升。  
**局限**：HML 在加入 RMW/CMA 后可能变得不显著（因子冗余）；模型不是“越复杂越好”的证明。

## 4.6 HXZ4：q-factor 模型（2015）

```
R_i − R_f = α_i + β_MKT·MKT + β_SMB·SMB + β_RMW·RMW + β_CMA·CMA + ε_i
```

- 来自 Hou-Xue-Zhang 的 q-factor 理论；
- 用**市场、规模、盈利、投资**四个因子；
- 不含 HML：价值在 q-factor 框架里不是独立因子，而是由投资/盈利驱动。

**贡献**：有明确的经济理论（投资学 q 理论），不是纯 empirical。  
**局限**：对因子构造（投资口径、盈利口径）敏感。

## 4.7 SY4：Stambaugh-Yuan 四因子（2017）

```
R_i − R_f = α_i + β_MKT·MKT + β_SMB·SMB + β_MGMT·MGMT + β_PERF·PERF + ε_i
```

- **MGMT**：管理相关因子（盈利能力/运营效率）；
- **PERF**：表现相关因子（动量/历史收益）。

> ⚠️ 本仓库没有 MGMT/PERF 的精确数据，notebook 用 **RMW/WML 作为近似代理**。
> 因此 notebook 里的 SY4 只是“SY4-like”，不能当作原模型结论。

## 4.8 DHS3：Daniel-Hirshleifer-Sun 三因子（2020）

```
R_i − R_f = α_i + β_MKT·MKT + β_FIN·FIN + β_PEAD·PEAD + ε_i
```

- **FIN**：融资因子（股票发行/回购）；
- **PEAD**：盈余公告后漂移（post-earnings announcement drift）。

> ⚠️ 本仓库没有 FIN/PEAD 的精确数据，notebook 用 **HML/WML 作为近似代理**。
> 因此 notebook 里的 DHS3 只是“DHS3-like”，不能当作原模型结论。

## 4.9 A 股被定价因子：原书结论（定性）

> 以下为原书/相关文献的 A 股结论概述，**不是本仓库 notebook 的数值结论**。

| 因子 | A 股是否被定价 | 方向/备注 |
|---|---|---|
| 市场 MKT | 多因子模型中不一定显著 | 定价基准，但显著性取决于模型 |
| 规模 SMB | 被定价 | 小市值长期有溢价，近年减弱、波动大 |
| 价值 HML | 被定价 | BM/EP 有解释力，会有长期跑输区间 |
| 动量 WML | 整体不显著 | A 股短期反转更常见 |
| 盈利 RMW | 被定价 | 质量/盈利与价值互补 |
| 投资 CMA | 整体不显著 | 对口径敏感 |
| 换手率 TURN | 被定价（负向） | 中国版三因子模型的重要成员 |

**中国版三因子（Liu et al. 2019）**：市场 + 市值 + EP（盈利市值比），并剔除壳价值污染；  
**中国版四因子**：在三因子上加盈利/质量。

## 4.10 怎么比较模型？

### ① GRS 检验（联合 α）

原假设：

```
H0: α_1 = α_2 = ... = α_N = 0
```

- p 值大 → 不能拒绝“所有 α 为零” → 模型通过体检；
- p 值小 → 模型解释不了某些收益 → 模型不够好；
- ⚠️ GRS 只回答“联合是否为零”，不指出**哪个**资产有问题；定位问题资产还要逐个 α 检验。

### ② 平均 |α| 与平均 R²

- **平均 |α|**：模型留下的定价误差，越小越好；
- **平均 R²**：模型解释的波动比例，越大越好；
- 两者要一起看：R² 高但 |α| 大，说明模型解释了波动、却没解释收益。

### ③ 嵌套 vs 非嵌套

- **嵌套模型**：FF3 ⊂ Carhart4、FF3 ⊂ FF5；可以用 GRS/α 检验比较“加因子是否值得”；
- **非嵌套模型**：HXZ4 vs FF5、SY4 vs DHS3；可以用**均值-方差张成**（一个模型的因子组合能否复制另一个模型的机会集）。

### ④ GRS 的功效问题

样本短、测试资产少、因子多时，GRS 可能“无力拒绝”任何模型（p 值都很大）。  
这时不要只看 p 值，要结合平均 |α|、R²、经济逻辑和样本外表现。

## 4.11 简约性：因子越多越好吗？

**不是。** 增加因子会：

- 提高 R²（拟合更好）；
- 但也可能引入噪声、增加过拟合、让系数不稳定；
- 因子之间高度相关时，还会互相“抢功劳”（多重共线性）。

实践中的简约原则：

1. 先有经济逻辑，再谈统计显著；
2. 3~5 个因子常常够用（FF3/FF5/HXZ4）；
3. 比较模型时，不要只比 R²，还要比平均 |α|、稳定性和可解释性；
4. 样本外有效，比样本内 R² 更重要。

| FF3 | MKT + SMB + HML | 市场、规模、价值 |
