## 1.1 一个公式看懂因子投资（01.1）

### 1.1.0 开场三问：因子投资到底在回答什么？

Notebook 一上来问了三个生活问题：

1. 为什么有些股票长期涨得比别的多？（白酒 vs 银行）
2. 为什么大盘一跌，几乎所有股票一起跌？（明明是不同的公司！）
3. 凭什么有人坚信“买便宜股”能赚钱？

**说人话**：

- 第一个问题：同样是股票，为什么“命”不一样？→ 因为它们背后的**风险来源**不一样。
- 第二个问题：为什么它们一起动？→ 因为它们**共同暴露**在同一个风险上（比如大盘）。
- 第三个问题：为什么“便宜”能赚钱？→ 因为“便宜”本身可能代表一种**被市场定价的风险**。

**一句话**：因子投资，就是研究“股票收益背后的共同原因”，以及“这些原因值多少钱”。

### 1.1.1 因子 = 食物的“营养成分”

Notebook 用的比喻：

> 米饭、肉、菜形态不同，但身体需要的是碳水、蛋白质、脂肪。  
> 股票形形色色，但收益背后是市场、规模、价值这些共同风险。

**说人话**：

- 你吃的是“菜”，但身体吸收的是“营养”；
- 你买的是“股票”，但收益驱动的是“因子”。

**因子的定义（背下来）**：

> 因子 = 众多资产共同暴露的系统性风险，是收益背后的驱动力。  
> 因子收益率 = 这种风险的风险溢价（共性收益）。

**两个必要条件**（判断一个东西是不是因子）：

1. **它得让很多资产一起动**（共同暴露、和协方差矩阵有关）；
2. **它得长期有正收益**（被市场定价，承担它有补偿）。

**判断口诀**：

> 它是很多股票收益的**共同原因**吗？长期持有它能**赚钱**吗？  
> 两个都“是”，才是因子。

**容易混淆**：

- 因子不是“某个指标”（比如“市盈率低”不是因子，低估值背后的风险才是）；
- 因子不是“保证赚钱的秘籍”，它只是“共同的风险来源”。

### 1.1.2 β = 暴露：你对这种风险敞开多少？

Notebook 里的案例 1：

- 模拟市场收益；
- 造两支股票：股票 A 对市场敏感（预设 β=1.2），股票 B 不敏感（预设 β=0.3）；
- 用回归的斜率估计 β。

输出：

```
股票A 的 β 估计 = 1.16（预设1.2）
股票B 的 β 估计 = 0.24（预设0.3）
```

**说人话**：

β 就是“市场涨 1%，这只股票平均跟涨多少”。

- β=1.2：市场涨 1%，它平均涨 1.2%，涨得比市场猛，跌得也比市场猛；
- β=0.3：市场涨 1%，它平均只涨 0.3%，比较“抗跌”，但也吃不到太多上涨。

**为什么估计是 1.16、0.24，不是正好 1.2、0.3？**

因为现实里有噪声。回归是从一段样本里“估”出来的，不可能分毫不差。**估计值接近预设值，就说明方法有效。**

**记忆钩子**：

> β 不是“风险大小”，而是“对某个因子的敏感度”。  
> 你对市场敏感，β 就高；你对市场无感，β 就低。

### 1.1.3 一个公式：E[R] = βλ + α

Notebook 给的公式：

```
E[R_i] = β_i λ + α_i
```

三个字母，说人话：

| 字母 | 含义 | 白话 | 记忆钩子 |
|---|---|---|---|
| β | 因子暴露 | 你对这种风险敞开多少 | **敞口** |
| λ | 因子溢价 | 这种风险值多少钱（月均） | **价格** |
| α | 定价误差 | 模型算不出的额外收益 | **私房钱** |

**把公式想成“配餐表”**：

- β：你这道菜里放了多少“营养”；
- λ：每单位营养值多少钱；
- βλ：按配餐表算出来的“标准营养价”；
- α：配餐表算不出来的“额外价值”（可能是真本事，也可能是称错了）。

Notebook 案例 2 用 4 支股票 × 2 个因子算了一遍：

- 因子 A 溢价 0.8%/月，因子 B 溢价 0.4%/月；
- 每支股票有两个 β；
- 矩阵乘法 `β @ λ` 得到预期收益。

输出：

| 资产 | β_A | β_B | E[R]模型（月） |
|---|---|---|---|
| stock_1 | 1.2 | 0.8 | 1.28% |
| stock_2 | 1.1 | 1.3 | 1.40% |
| stock_3 | 0.9 | -0.8 | 0.40% |
| stock_4 | 0.8 | -1.3 | 0.12% |

**怎么读这张表**：

- stock_1：1.2×0.8% + 0.8×0.4% = 0.96% + 0.32% = **1.28%**；
- stock_2：1.1×0.8% + 1.3×0.4% = 0.88% + 0.52% = **1.40%**；
- stock_3：0.9×0.8% + (-0.8)×0.4% = 0.72% - 0.32% = **0.40%**；
- stock_4：0.8×0.8% + (-1.3)×0.4% = 0.64% - 0.52% = **0.12%**。

**记忆钩子**：

> **E[R] = βλ + α**  
> 收益 = 你承担了多少风险 × 风险值多少钱 + 模型没算到的部分。

### 1.1.4 α = 异象：模型解释不了的“私房钱”

Notebook 案例 3：

- 给 stock_2 注入 1.2%/月的真实 α；
- 其他股票 α=0；
- 画图：红点（异象）到模型直线的垂直距离，就是 α。

**说人话**：

- 模型说 stock_2 应该赚 1.40%/月；
- 实际它赚了 1.40% + 1.20% = 2.60%/月；
- 多出来的 1.20%，模型解释不了，就叫 **α**；
- 如果这个 α 是真实、稳定、显著的，它就是一个**异象**。

**为什么叫“异象”？**

因为“模型说不可能，但数据里就是有”。它可能是：

- 真本事（选股、重组、运营）；
- 真风险（模型漏掉的风险因子）；
- 或者只是运气/数据窥探（第 1.2 节会讲）。

**记忆钩子**：

> α 是“点到模型直线的垂直距离”。  
> α=0，点在线上；α≠0，点飞出去了。

### 1.1.5 截面 vs 时序 + 降维魔法

Notebook 用两个生活例子区分：

- **截面**：为什么北京比鹤岗贵？（不同资产之间的收益差异）
- **时序**：北京今年比去年涨了多少？（同一资产随时间的变化）

**说人话**：

- 截面 = **同一时间，不同资产比高低**；
- 时序 = **同一资产，不同时间看变化**。

因子投资两边都用：

- 截面：按因子给股票排队、分组，看哪组收益高；
- 时序：看因子收益随时间怎么变，算协方差、做风险模型。

**降维魔法**：

```
Σ = β Σ_λ β' + Σ_ε
```

**说人话**：

- 3000 支股票，两两算协方差，是 3000×3000 的矩阵，对称矩阵约 450 万个独立数字；
- 用 10 个因子，只需要估 10×10 的因子协方差 + 每支股票的特质风险；
- 这就是“因子模型 = 协方差矩阵降维”，也是 Barra 风险模型的基础。

Notebook 案例 4：

- 模拟 120 个月，用因子模型重建协方差，再和真实样本协方差比较；
- 输出最大误差 **0.00043**。

**怎么读**：

- 误差不是 0，因为样本有噪声；
- 但误差很小，说明“协方差确实可以拆成因子部分 + 特质部分”；
- 这就是“降维”的数学依据。

**记忆钩子**：

> 3000×3000 太胖，10×10 刚好。  
> 因子模型，就是给协方差矩阵“减肥”。

### 1.1.6 动手任务：怎么验证自己真懂了？

Notebook 留了三个“试一试”：

1. 把 `alpha` 全部改成 0 重跑案例 3——红色竖线会发生什么？  
   **答案**：红色竖线消失，所有点回到模型直线上。说明 α 就是“点到线的距离”。
2. 给 teach 加一行新股票（β=[1.0, 0.6]），算它的 E[R]。  
   **答案**：1.0×0.8% + 0.6×0.4% = 1.04%/月。
3. 把 `cov_lam` 的非对角元改成 0.0005 重跑案例 4——误差变大还是变小？  
   **答案**：误差会变大，因为因子之间的相关性变了，模型设定和真实数据不一致；这说明“协方差结构”很重要。

### 1.1.7 本课记忆卡

- 因子 = 营养成分；两个条件：共同运动 + 长期正溢价。
- β = 敞口；λ = 价格；α = 私房钱。
- **E[R] = βλ + α**。
- 截面 = 不同资产比高低；时序 = 同一资产看变化。
- 协方差 = 因子部分 + 特质部分；因子模型 = 降维。

## 1.2 学术起源：三位诺奖与“因子动物园”（01.2）

### 1.2.1 时间线：因子研究是怎么一步步长出来的？

Notebook 给了一条故事线：

| 年份 | 事件 | 说人话 |
|---|---|---|
| 1934 | Graham & Dodd《证券分析》 | “便宜股”思想的源头：买得便宜，留安全边际 |
| 1960s | CAPM 问世 | 第一次用公式说清“风险—收益”：β 高，预期收益高 |
| 1976 | APT（Ross） | 从一个因子推广到多个因子：不止市场一个风险 |
| 1977/1981 | 便宜股效应、小市值效应被发现 | CAPM 解释不了它们——这就是“异象” |
| 1993 | Fama-French 三因子 | 把两个异象“收编”成 SMB 和 HML 因子 |

**规律（很重要）**：

> **异象倒逼模型升级 → 模型把异象收编成因子 → 新异象出现 → ……**

**说人话**：

- 先有一个“解释不了的现象”（异象）；
- 学者想办法把它变成“可解释的风险”（因子）；
- 模型升级；
- 然后又发现新的解释不了的现象；
- 循环往复。

这就是因子研究的历史：不是一开始就有七个因子，而是“打补丁”打出来的。

### 1.2.2 三位诺奖：他们各自贡献了什么？

2013 年诺贝尔经济学奖给了三位：Fama、Hansen、Shiller。

**Fama（有效市场之父）**：

- **联合假说（1970）**：想检验市场有没有效，先得有“对的尺子”（定价模型）。  
  说人话：你说市场错了，得先有一个“对的价格”标准；否则你凭什么说它错？
- **Fama-MacBeth 回归（1973）**：检验模型的统计工具。第 2 章会详讲。
- **FF 三因子模型（1993）**：市场、规模、价值。

**Hansen**：

- **GMM（1982）**：检验模型的“万能账本”。  
  说人话：先写“账应该怎么平”（矩条件），再拿数据对账；账不平，模型就有问题。

**Shiller（行为金融）**：

- **噪音交易者模型（1984）**：价格会涨过头、跌过头，因为人不是完全理性的。

**最关键的一点**：

> Fama 认为市场有效，Shiller 认为市场常犯错——两人的立场相反。  
> **因子投资，就诞生在这两种立场的拉扯中**：  
> 有效市场需要因子（风险补偿）；行为金融需要异象（错误定价）。

**记忆钩子**：

> Fama 给尺子，Hansen 给账本，Shiller 给“人会犯错”的理由。

### 1.2.3 案例 1：数据窥探——随机数里也能挖出“显著因子”

Notebook 做了一个很“扎心”的实验：

- 生成 **1000 个纯随机噪声序列**（市场里根本不存在任何因子）；
- 每个序列 120 期；
- 用“|t| > 2 就算显著”的标准去挖。

输出：

```
纯噪声序列中，|t|>2 的「显著因子」: 42 个 / 1000 (4.2%)
```

**说人话**：

- 明明全是噪声，居然有 42 个“显著因子”；
- 因为 5% 显著性水平，本来就会放进来约 5% 的假阳性；
- 1000 个里出现 42 个（4.2%），非常正常。

**这意味着什么？**

> 如果你试了 1000 个因子，即使它们全是垃圾，也会有几十个看起来“显著”。  
> 这就是 **数据窥探（data snooping）**：先射箭，再画靶。

**怎么破？**

- 提高门槛：|t| > 3.0 或 3.4（Harvey/Chordia）；
- 样本外检验；
- 多重检验校正；
- 先有经济逻辑，再看数据。

**记忆钩子**：

> 1000 个噪声 → 42 个“显著”（4.2%）。  
> 试得够多，总能“显著”。

### 1.2.4 因子动物园：400+ 因子，大多数不可信

Notebook 给了三个数字：

| 事实 | 出处 |
|---|---|
| 学术界已挖出 **400+** 个因子 | Cochrane (2011) |
| 显著性门槛从 t=2.0 抬到 **3.0** | Harvey et al. (2016) |
| 再抬到 **3.4**；发表后收益平均**衰减 50%+** | Chordia (2020)、McLean & Pontiff (2016) |

**说人话**：

- 400+ 因子，就像动物园里塞满了各种“神兽”；
- 很多是数据窥探的产物：试出来的，不是想出来的；
- 门槛提高，是因为“试了很多次”后，t=2 已经不够用了；
- 发表后衰减，是因为“网红店红了就排队，利润被摊薄”。

**记忆钩子**：

> **400+ 因子，t 从 2 到 3 到 3.4，发表后衰减 50%+。**  
> 看到一个新因子，先问：样本外还活着吗？

### 1.2.5 案例 2：发表后衰减——挑最好区间发表，长期会怎样？

Notebook 模拟：

- 真实月均溢价 0.4%，噪声 3%，共 240 个月；
- 研究者挑“表现最好的 60 个月”发表；
- 再看全样本（长期真相）。

输出：

```
发表前（挑最优区间）月均: 0.58%
发表后（长期真相）月均:   -0.05%
衰减幅度: 108%（真实世界中 McLean-Pontiff 测得 ~50%+）
```

**说人话**：

- 发表前：挑了最好的一段，月均 0.58%，看起来很美；
- 发表后：全样本平均 -0.05%，其实是负的；
- 衰减 108%，意思是“把发表前的收益全还回去还不够”。

**为什么是 108%，不是 50%？**

- 这是一次模拟的结果，随机性很大；
- 真实世界平均约 50%+，但个体可能更夸张；
- 重点不是“108%”这个数，而是“**挑区间会让收益看起来比真实好很多**”。

**记忆钩子**：

> 挑最好区间 = 把照片修过再相亲。  
> 见真人（样本外）才发现，差距很大。

### 1.2.6 本课记忆卡

- 时间线：Graham → CAPM → APT → 异象 → FF3。
- 三位诺奖：Fama 尺子、Hansen 账本、Shiller 人性。
- 数据窥探：1000 个噪声，42 个“显著”（4.2%）。
- 因子动物园：400+ 因子，t 门槛 2→3→3.4，发表后衰减 50%+。
- 读论文三问：**样本外？换口径？有经济逻辑？**

## 1.3 业界全景：管理人怎么用？投资者怎么买？（01.3）

### 1.3.1 管理人视角：五件事

Notebook 列了管理人用因子的五件事：

| # | 关键词 | 说人话 |
|---|---|---|
| 1 | 收益预测 vs 风险管理 | 因子既能选股（截面），也能算协方差控风险（时序） |
| 2 | 因子拥挤 | 用的人越多越不赚钱，出事时互相踩踏（2007年8月量化危机） |
| 3 | 因子择时 | 因子时灵时不灵，能躲开吗？（RA 按估值 vs AQR 按动量） |
| 4 | α vs β 收益 | 管理人赚的钱里 ~80% 来自 β（因子暴露），只有 20% 是真 α |
| 5 | 创新 | 另类数据（舆情/专利/新闻）+ 机器学习 = 新收益源 |

**说人话**：

- 因子不只是“选股信号”，还是“风险语言”；
- 因子会拥挤：大家都知道、都去用，收益就被摊薄，甚至踩踏；
- 因子择时很难：你以为在躲风险，可能只是错过反弹；
- 管理人的收益，大部分是“风格/β”，小部分才是“真本事/α”；
- 新数据、新方法，是寻找新 α 的方向，但也容易过度拟合。

### 1.3.2 案例 1：电梯类比——顶尖管理人靠电梯还是俯卧撑？

Notebook 模拟 100 个管理人：

```
收益 = 80% × β × 市场 + 20% × α 能力 + 运气
```

然后看业绩最好的 10 个，是靠“电梯”（β）还是“俯卧撑”（α）。

输出（节选）：

| 年化收益% | β暴露（电梯） | α能力（俯卧撑）% |
|---|---|---|
| 13.31 | 1.47 | 0.27 |
| 11.94 | 1.07 | 0.19 |
| 11.57 | 1.39 | 0.19 |
| 11.20 | 1.30 | 0.13 |
| 11.16 | 1.19 | 0.19 |
| ... | ... | ... |

**说人话**：

- 业绩最好的 10 个，β 大多在 0.9~1.5 之间，偏高；
- α 能力都在 0.1%~0.3% 左右，差距不大；
- 结论：**在模拟里，顶尖管理人主要是“电梯快”，不是“俯卧撑强”。**

**注意**：

- “80% 来自 β”是模拟设定，不是宇宙真理；
- 但它提醒你：评价一个基金，先问“它是不是选对了风格/暴露”，再问“它有没有真 α”。

**记忆钩子**：

> 管理人的收益 = 电梯（β）+ 俯卧撑（α）。  
> 先看电梯，再看俯卧撑。

### 1.3.3 投资者视角：从风格指数到 Smart Beta

Notebook 给了一条简史：

- **1987**：Russell 推出最早风格指数（价值/成长）；
- **1992**：先锋推出价值指数基金——主动投资的低成本替代；
- 今天：Smart Beta ETF 规模超 **6500 亿美元**（2018 年估算）——普通投资者“一键买入因子”。

**说人话**：

- 以前：想买“价值风格”，得找主动基金；
- 后来：有了价值指数基金，费率低；
- 现在：Smart Beta ETF，把“因子”做成产品，像买普通 ETF 一样买因子。

**但选 ETF 很难**：

Choi et al. (2009) 实验发现：连金融专业学生都会被“历史收益”迷惑，忽视费率。

### 1.3.4 案例 2：选 ETF 实验——同一因子，只看费率

Notebook 模拟 5 个 ETF：

- 追踪**同一个价值因子**；
- 毛收益完全相同；
- 只有费率不同：0.05%、0.10%、0.20%、0.35%、0.50%；
- 加上随机扰动，模拟“历史表现差异”。

**第一眼（看历史收益）**：

```
ETF_5(费率0.5%)     0.273  ← 看起来最高
ETF_1(费率0.05%)    0.270
ETF_2(费率0.1%)     0.269
ETF_3(费率0.2%)     0.234
ETF_4(费率0.35%)    0.220
```

**扣费后（真实收益）**：

```
ETF_1(费率0.05%)    0.283  ← 真正最高
ETF_2(费率0.1%)     0.279
ETF_3(费率0.2%)     0.273
ETF_4(费率0.35%)    0.264
ETF_5(费率0.5%)     0.254
```

**说人话**：

- 5 个 ETF 跟踪同一个因子，长期毛收益应该差不多；
- 历史收益的差异，很多是随机噪声；
- 真正确定性的差异，是**费率**；
- 所以：**同类 ETF，先看费率，再看别的。**

**记忆钩子**：

> 同一个因子，费率低的赢。  
> 不要被“过去 5 年收益”迷惑，那可能只是噪声。

### 1.3.5 本课记忆卡

- 管理人五件事：收益/风险、拥挤、择时、α vs β、创新。
- 电梯类比：80% β + 20% α；先看电梯，再看俯卧撑。
- 投资者：风格指数 → Smart Beta ETF；同类 ETF 只看费率。
- 选 ETF 实验：毛收益 ETF_5 最高，扣费后 ETF_1 最高。

## 1.4 全章串联：一张图记住第 1 章

```
股票收益
   │
   ├─ 共同原因（因子）
   │     ├─ 市场
   │     ├─ 规模
   │     └─ 价值
   │
   ├─ β：你对因子的暴露（敞口）
   ├─ λ：因子的价格（溢价）
   ├─ βλ：多因子模型算出的“标准收益”
   └─ α：模型解释不了的“私房钱”（异象）

截面：不同资产比高低
时序：同一资产看变化
协方差：Σ = βΣλβ' + Σε（降维）

学术界：异象 → 模型 → 新异象（数据窥探要小心）
业界：管理人 = 电梯 + 俯卧撑；投资者 = Smart Beta + 费率
```

**如果只记 5 句话**：

1. 因子是股票收益的“营养成分”，两个条件：共同运动 + 长期正溢价。
2. β 是敞口，λ 是价格，α 是私房钱。
3. **E[R] = βλ + α**。
4. 数据窥探：1000 个噪声能挖出 42 个“显著因子”；t 门槛 2→3→3.4。
5. 管理人 80% 收益来自 β；同类 ETF 只看费率。

## 1.5 自测题（先答，再看答案）

### Q1：因子的两个必要条件是什么？

**答案**：

1. 众多资产共同暴露（一起动）；
2. 长期有正的风险溢价（被定价）。

### Q2：β、λ、α 各是什么？

**答案**：

- β：对因子的暴露/敏感度；
- λ：因子的风险溢价（市场为承担风险支付的价格）；
- α：模型解释不了的定价误差/超额收益。

### Q3：某股票 β_A=1.2，β_B=0.5；λ_A=0.8%/月，λ_B=0.4%/月。它的模型预期收益是多少？

**答案**：

1.2×0.8% + 0.5×0.4% = 0.96% + 0.20% = **1.16%/月**。

### Q4：α=0 和 α≠0 分别意味着什么？

**答案**：

- α=0：模型能解释它的收益；
- α≠0：模型解释不了，可能是异象、漏掉的风险、运气或数据窥探。

### Q5：截面和时序有什么区别？

**答案**：

- 截面：同一时间，不同资产比较（北京 vs 鹤岗）；
- 时序：同一资产，不同时间比较（北京今年 vs 去年）。

### Q6：什么是数据窥探？为什么 1000 个噪声能挖出 42 个“显著因子”？

**答案**：

- 数据窥探：先看数据、再编故事（先射箭再画靶）；
- 5% 显著性水平下，本来就有约 5% 的假阳性；1000 个噪声出现 42 个（4.2%）很正常。

### Q7：为什么 t 门槛要从 2.0 提高到 3.0/3.4？

**答案**：

- 因为研究者会试很多因子/口径/区间，传统 5% 门槛会产生大量假阳性；
- 提高门槛是对多重检验的校正，代价是可能漏掉真因子。

### Q8：电梯类比和 ETF 实验，各说明什么？

**答案**：

- 电梯类比：管理人收益大部分来自 β（风格/暴露），小部分来自 α（真本事）；评价基金先看 β。
- ETF 实验：同一因子、同一毛收益，费率决定长期净收益；不要被历史收益的噪声迷惑。

## 1.6 六个最容易混淆的点

| 容易混淆 | 正确理解 |
|---|---|
| 因子 = 某个指标 | 因子是共同风险；指标只是代理变量 |
| β = 风险大小 | β 是对某个因子的敏感度；风险还包括特质风险 |
| α = 一定是能力 | α 可能是能力、漏掉的风险、运气或数据窥探 |
| 相关 = 因果 | 一起动不等于谁导致谁；要找经济逻辑 |
| 样本内 = 真相 | 样本内可以挑出来；样本外才见真章 |
| 模型 = 现实 | 模型是地图，不是领土；模型会错位 |

## 1.7 怎么复习：三遍法

**第一遍：看故事**

- 因子=营养成分；β=敞口；λ=价格；α=私房钱；电梯=β；俯卧撑=α。
- 不追求公式，先有画面。

**第二遍：跑 notebook**

- 打开三个 notebook，逐个运行；
- 改一个参数，看输出怎么变（尤其是 α=0、t 阈值、费率）；
- 把“输出数字”和“概念”对上。

**第三遍：合上笔记，复述**

- 拿一张白纸，写下 E[R]=βλ+α，并解释三个字母；
- 说出三个案例：β 回归、α 异象、协方差降维；
- 说出三个数字：42/1000、t 2→3→3.4、80/20；
- 如果能把一个没学过金融的朋友讲懂，你就真懂了。

**10 分钟复习版**：

1. 写公式：E[R]=βλ+α；
2. 解释 β、λ、α；
3. 讲一个例子：茅台 β 高 vs 银行 β 低；
4. 讲一个警告：1000 个噪声 → 42 个“显著”；
5. 讲一个业界结论：管理人 80% 收益来自 β；同类 ETF 看费率。

> 第 1 章不是让你变成量化专家，而是让你拥有一个“看收益”的统一框架。  
> 记住一句话：**先问“这是哪个因子”，再问“这是不是真本事”。**
