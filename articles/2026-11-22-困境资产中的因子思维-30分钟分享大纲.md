# 《困境资产中的因子思维》30 分钟分享大纲

> 适用场景：投资团队内部分享 / 投委会方法论培训 / 行业沙龙  
> 配套材料：文章《困境资产中的因子思维》、工作流图  
> 目标：不是讲量化，而是讲一套“反叙事”的判断纪律

## 一、分享目标（讲完听众应记住）

1. **一个公式**：收益 = βλ + α；先分清共同原因，再谈个体能力。
2. **一套流程**：定义 → 数据 → 特征 → 排序/回归 → 稳健性 → 组合/归因。
3. **三条纪律**：先看样本外，再信样本内；先扣 beta，再谈 alpha；先做归因，再谈成功。

## 三、Slide-by-slide

### Slide 1｜封面（0:00–0:01）
- 标题：困境资产中的因子思维
- 副标题：从“故事”到“可检验的证据”
- 演讲人 / 日期 / 内部交流

### Slide 2｜开场：你听到的是故事，还是证据？（0:01–0:03）
- 四个典型句子：
  - “核心地段，只是股东流动性问题”
  - “三折买入，闭着眼都不会亏”
  - “上一轮周期我就是这么赚的”
  - “这家公司基本面没问题，只是被抽贷了”
- 互动：请听众选一个“最像自己听过的话”
- 结论：故事不一定错，但故事不是证据

### Slide 3｜困境资产的五个特殊性（0:03–0:05）
- 样本少：一年看几十个，成交个位数
- 周期长：3~7 年才反馈
- 异质性强：法律、资产、区域、债务人各不同
- 幸存者偏差：失败者不再发声
- 叙事驱动：越便宜，故事越动人
- 一句话：**样本少 + 反馈慢 + 叙事强 = 最容易把 beta 当 alpha**

### Slide 4｜一个公式：E[R] = βλ + α（0:05–0:08）
- β：对共同风险的暴露
- λ：市场为风险支付的价格
- α：模型解释不了的超额收益
- 例子：周期底部买什么都能赚（β）；信用利差高位买债（β）；高杠杆放大 beta（β）
- 关键问题：**扣掉 β 之后，你的 α 还在不在？**

### Slide 5｜把公式翻译到困境资产（0:08–0:10）
- 表格：因子投资 ↔ 困境资产
  - 市场/行业/风格 ↔ 利率、信用利差、地产周期、区域流动性、法律/监管
  - β ↔ 项目对共同风险的敏感度
  - λ ↔ 市场要求的折价/回报
  - α ↔ 项目选择、重组、法律执行、运营、退出
- 一句话：**困境资产不是没有因子，而是因子藏得更深**

### Slide 6｜第2章：把“感觉”变成“证据”（0:10–0:16）
- 排序法：按折扣率/LTV/质量/法律复杂度分组，比较高组 vs 低组
- 时序回归：每个项目对共同因子的 β 和 α
- 截面/FM：市场为哪类风险付钱；每期回归再平均
- NW/GRS：标准误与联合检验
- 正交化：剔除“便宜=质量差/法律复杂”的重复信息
- 一句话：**先分组，再回归；先控制，再解释**

### Slide 7｜工作流图（0:16–0:18）
- 展示六步工作流图
- 强调：这不是“量化部门的流程”，而是“任何项目都能用的研究流程”
- 六步：定义 → 数据 → 特征 → 排序/回归 → 稳健性 → 组合/归因

### Slide 8｜第6章：别让“研究”变成“数据窥探”（0:18–0:20）
- p-hacking：只挑成功案例、只挑好年份、先看项目再编逻辑
- 策略动物园：每个策略都有成功案例，但跨周期/跨区域/扣成本后还成立吗？
- 三个问题：样本外？换口径？有经济逻辑？
- 一句话：**试得够多，总能“显著”；先怀疑，再验证**

### Slide 9｜行为金融：错误定价从哪里来？（0:20–0:22）
- 四来源：套利限制、预期偏差、风险偏好偏差、认知限制
- 困境资产例子：
  - 套利限制：资金久期、牌照、法律程序、资产不可分割
  - 预期偏差：过度悲观/过度乐观、锚定原估值
  - 风险偏好：损失厌恶、处置效应
  - 认知限制：只看熟悉区域/资产
- 一句话：**错误定价 = 偏差 + 套利限制；两者同时存在才是机会**

### Slide 10｜第7章：风险、组合、归因（0:22–0:25）
- 风险模型：Σ = BΣ_fB' + D；真分散 vs 假分散
- 组合优化：小心“误差最大化器”；加约束
- Smart Beta：把策略规则化
- 风格分析/归因：收益 = 因子贡献 + α；风险 = 因子 + 特质
- 一句话：**收益模型决定偏不偏，风险模型决定稳不稳，归因决定知不知**

### Slide 11｜三个常见误区（0:25–0:27）
- 把 beta 当 alpha
- 把样本内当样本外
- 把模型当真相
- 每个误区配一个困境资产例子

### Slide 12｜尽调十问（0:27–0:28）
1. 这个项目的收益，多少来自周期/区域/流动性？
2. 我的 β 是什么？
3. 信用利差走阔 200bp，回收率怎么变？
4. 我的“便宜”是不是“质量差/法律复杂”的代理？
5. 成功案例的完整样本是什么？
6. 我试了多少种退出假设？
7. 交易对手/债权人/开发商是否与我其他项目重叠？
8. 压力情景下，我的组合相关性会怎样？
9. 扣掉 beta/成本后，我的 α 还显著吗？
10. 什么证据会证明我错了？

### Slide 13｜结语：四句话（0:28–0:30）
- 收益 = βλ + α
- 先分清共同原因，再谈个体能力
- 先看样本外，再信样本内
- 先做归因，再谈成功
- 最后一句：**因子研究不是寻找圣杯，而是用证据保护判断，用归因持续学习。**

### Slide 14｜Q&A
- 预设问题：
  - “困境资产样本这么少，怎么做统计？”
  - “β 怎么定义？宏观因子怎么选？”
  - “这套方法能直接指导投决吗？”
  - “怎么说服投委会/老板？”
- 回答原则：先讲经济逻辑，再讲统计；先讲局限，再讲结论

## 四、演讲提示

- 不要一上来讲公式，先用“你听过哪句话”让听众代入；
- 每讲一个方法，配一个困境资产例子；
- 不要贬低“故事”，而是说“故事是起点，证据是终点”；
- 控制时间：第2章和第6章是重点，第7章点到为止；
- 结尾留 2 分钟 Q&A，不要拖堂。
